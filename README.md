# Путь домой

![C++](https://img.shields.io/badge/C%2B%2B-SFML-00599C?logo=cplusplus)
![SFML](https://img.shields.io/badge/SFML-2.5.1-8CC445)
![Genre](https://img.shields.io/badge/genre-space%20arcade-191970)

Космическая аркада о возвращении корабля на Землю. Игрок проходит несколько
последовательных участков пути, уклоняется от метеоритов, космического мусора
и других кораблей, собирает топливо и следит за прогрессом на радаре.

## Игровой процесс

- движение расходует запас топлива;
- канистры восстанавливают разное количество топлива;
- столкновение с опасным объектом приводит к поражению;
- сложность и скорость объектов растут по мере продвижения;
- маршрут состоит из нескольких фаз: метеориты, мусор и корабли;
- индикатор в верхней панели показывает расстояние до Земли;
- после прохождения всех участков появляется финальный экран.

## Управление

| Клавиши | Действие |
|---|---|
| `WASD` или `Num 8/4/5/6` | движение корабля |
| `Pause` | пауза |
| `M` | включить или отключить музыку |
| `R` | начать путь заново |
| `End` | выйти |

## Архитектура

| Файл | Назначение |
|---|---|
| `main.cpp` | основной цикл, этапы маршрута, UI и правила |
| `ExternalWorld.*` | препятствия, бонусы, скорость и повторное появление объектов |
| `GameLibrary.*` | вспомогательные функции анимации, текста и движения |
| `Image` | корабль, космос, Земля, препятствия и интерфейс |
| `Music` | музыка и звуковые эффекты |
| `Font` | шрифт интерфейса |

## Сборка

Проект предназначен для Windows, Visual Studio 2022 и SFML 2.5.1 x64.

1. Установите SFML, собранную для вашей версии MSVC и архитектуры x64.
2. Откройте `Простая игра SMFL.sln`.
3. В свойствах проекта замените пути к `SFML/include` и `SFML/lib`.
4. Выберите `Debug x64` или `Release x64` и соберите решение.
5. Запускайте программу с рабочим каталогом корня репозитория: относительные
   пути должны видеть папки `Image`, `Music` и `Font`.

> CMake-конфигурации в репозитории пока нет. DLL SFML находятся в проекте,
> однако они должны соответствовать выбранной конфигурации и компилятору.

## Статус

Играбельный учебный прототип. Полезные направления развития: перевод логики
этапов в конечный автомат, хранение объектов в `std::vector`, экран настроек и
независимое от FPS движение всех элементов.
